# RewrZ 变更记录

本文档只在**发布正式版本**时更新：发布前把该周期内的全部变更按主题汇总成一条版本记录，日常提交不再逐次修改本文件。

- 单个提交不追加条目，避免文件体积随提交次数线性膨胀。
- 只记录最终结论（功能、修复、性能、部署影响），不写修订过程与中间尝试。
- 已发布版本按日期倒序保留，不维护占位版本号或文档初始化记录。

## v3.2（2026-11-12）

自 v3.1 起的功能与治理合版，涵盖内容模型、写作体验、主题视觉、安全与容量、部署运维五条线。

### 功能
- 内容模型：新增分类描述与标签词条释义并在前台聚合页露出；新增内容分级（通用 / 敏感 / NSFW）与 NSFW 分发隔离，是否允许搜索引擎收录改为站点级可配置；分类与标签聚合页统一布局并保留视觉差异。
- 写作体验：文章与页面编辑器重做布局，新增 Markdown 版式区块、历史快照、文章列表内联编辑；正文支持拖拽 / 粘贴上传、快捷保存与离开提醒；发布设置与工具栏按桌面、移动端分别收敛。
- 内容形态：新增文章详情模板与格式内预设，重做微博时间线与首页诗词聚合，首页时光轴背景容器支持后台开关；前台支持微博快速编辑。
- 主题系统：前后台统一动态主题变量与背景图，新增背景特效滤镜与实时预览；编辑器、卡片、按钮、提示条不再写死颜色。
- 运维能力：新增 SQLite 压缩与空间预警，访问统计趋势图补双纵轴并修正移动端时间标签与异常表。

### 修复与治理
- 安全：收敛后台权限与评论解锁，媒体变体加签名并接入运行时缩略图配置，加固评论反滥用、部署防护与上传链路。
- 性能：新增公开列表 / 详情缓存、浏览量内存计数批量落库、垃圾爬虫拦截；收敛事件循环上的同步数据库操作，修复连接池耗尽。
- 数据：修复历史快照从未落库、WordPress 导入媒体附件遗漏、搜索结果阅读量恒为 0、订阅裸路径 404、RSS / Atom 输出口径不一致；导入导出补齐描述与释义字段。
- 编辑器：修复后台局部导航下 Toast UI 资源异步加载导致的偶发 `toastui is not defined`，编辑器依赖固定到全局 head；清理媒体库缩略图冗余懒加载。
- 视觉：修复后台主题跨设备同步、媒体库重复卡片与 0B 大小、快照预览与对比、编辑器体验问题。

### 部署
- 最低运行环境提升至 Python 3.12，依赖同步升级；`update.sh`、`docs/operations/UPDATE.md`、`docs/operations/DEPLOYMENT.md` 已同步。
- 本版本包含新的 Alembic 迁移（标签 `description` 列），生产更新需执行 `alembic upgrade head`。
